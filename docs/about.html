About the Project

HUDOC Researcher — search, analytics, and open data for human rights research

What is this?

HUDOC Researcher is a paragraph-level companion to the European Court of Human Rights. It indexes every paragraph of 20,123 judgments (up to 8 October 2026), each with the Court’s own paragraph number and the part of the judgment it belongs to, so that a search lands on the passage you will cite — and then sends you to HUDOC, the authoritative source, for the full text.

  • Search — full text with HUDOC’s operators, the parts of the judgment to search in, filters, and each judgment’s Cites / Cited by.
  • Semantic Search (experimental) — describe a case in plain language.
  • Check — paste a text: every citation, paragraph number and quotation is checked against the judgments.
  • Workspace — paragraphs and searches you save, with your notes, kept in your browser.
  • Statistics — the corpus in charts.
  • AI assistant (MCP) — the same search from Claude or another assistant, quoting paragraphs verbatim.

How the data was built and checked is set out in the Methodology.

Use it from your AI assistant (MCP)

The corpus is also available as a Model Context Protocol server, so an AI assistant (Claude, or any client that supports MCP) can search the judgments and quote paragraphs verbatim, each with its case name, application number, date and paragraph number, instead of paraphrasing from memory. It offers seven tools: echr_search (paragraph search with the same filters as Search), echr_get_case, echr_get_paragraphs, echr_cited_by and echr_cites (the citation links), echr_facets and echr_stats.

It runs on your computer and queries this site’s API; you need Node.js 18 or newer.

  1. Download it and install its dependencies: 
    git clone https://github.com/lszoszk/mcp-echr.git
cd mcp-echr
npm install
  2. Claude Desktop: add this to claude_desktop_config.json (Settings → Developer → Edit Config), with the folder you cloned into, then restart Claude: 
    {
  "mcpServers": {
    "echr": {
      "command": "node",
      "args": ["/ABSOLUTE/PATH/TO/mcp-echr/src/index.js"]
    }
  }
}
    Claude Code: one command instead: 
    claude mcp add echr -s user -- node /ABSOLUTE/PATH/TO/mcp-echr/src/index.js
  3. Ask, for example: “Find Grand Chamber paragraphs on the margin of appreciation under Article 10 and cite them with paragraph numbers.”

Source and full instructions: github.com/lszoszk/mcp-echr. As with the website, check any passage you rely on in HUDOC.

Scope and limits

  • Independent and not legal advice: an academic research tool, not affiliated with, endorsed or operated by the European Court of Human Rights or the Council of Europe. HUDOC remains the authoritative source of every judgment: check any passage you rely on there.
  • Judgments, in English: Grand Chamber, Chamber and Committee judgments that HUDOC has in English, plus a few dozen Grand Chamber admissibility decisions (shown when Decisions is ticked). HUDOC’s other collections are not included. About 9,300 judgments exist only in French; unofficial English machine translations of the 2,460 most-cited of them can be switched on in Search, clearly labelled (see the Methodology).
  • Up to a cut-off date: the newest judgment is dated 8 October 2026. The corpus is topped up monthly, and HUDOC renders the source documents some weeks after the Court publishes, so the last weeks are thinner than they will be.
  • Paragraph numbers are those printed in the judgment; in older judgments a few are missing or wrong. Verify a pinpoint on HUDOC before citing it.
  • Where it differs from HUDOC: HUDOC searches whole documents; this tool searches individual paragraphs, and HUDOC’s default search leaves out Committee judgments, which are included here, so counts can exceed a default HUDOC search.

The technical limits — of the segmentation, the citation counts and the older templates — are in the Methodology.
